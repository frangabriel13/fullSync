# FullSync

Landing page de FullSync, empresa de soluciones IT.

## Stack

Vite · React · TypeScript · CSS Modules · react-icons

## Uso

```bash
npm install
npm run dev      # desarrollo en http://localhost:5173
npm run build    # build de producción en /dist
npm run preview  # previsualizar el build
npm run lint     # ESLint
```

## Estructura

```
src/
  components/  componentes reutilizables
  layout/      Header y Footer
  sections/    secciones de la landing
  data/        contenido editable (textos, servicios, FAQ, contacto)
  styles/      variables y estilos globales
```

Para cambiar textos o datos de contacto, editá los archivos de `src/data`.
